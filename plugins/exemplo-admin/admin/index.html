Plugin Autoloader — Exemplo

Este módulo foi carregado automaticamente pelo sistema de autoloading. Para criar o seu próprio módulo, basta criar uma pasta em plugins/seu-plugin/admin/ com 3 arquivos.

Estrutura de arquivos

plugins/
  seu-plugin/
    admin/
      manifest.json   ← metadados (nome, grupo, ícone, ordem)
      index.html      ← conteúdo da aba (HTML puro)
      index.js         ← lógica da aba (JS puro)
    index.js          ← rotas do servidor (opcional)
    package.json      ← versão e descrição (opcional)

manifest.json

{
  "name": "meu-plugin",
  "displayName": "Meu Plugin",
  "description": "Descrição do plugin",
  "group": "Cadastros",
  "order": 50,
  "icon": "ph-star"
}
Campos:
• name — ID único do plugin
• displayName — Nome exibido na aba
• group — Grupo no sidebar (criado automaticamente)
• order — Ordem dentro do grupo (menor = primeiro)
• icon — Classe do Phosphor Icons (ph-*)

index.js

// Função chamada quando a aba é aberta pela primeira vez
window.plugin_meu-plugin_init = function({ tab, tabId, plugin }) {
  console.log('Plugin ' + plugin.name + ' inicializado!');
  // 'tab' é o elemento DOM da aba
  // 'tabId' é 'plugin-seu-plugin'
  // 'plugin' é o objeto manifesto
};

Como usar no seu projeto:
Crie uma pasta plugins/nome-do-plugin/admin/ com esses 3 arquivos. O servidor escaneia automaticamente e a aba aparece no admin panel. Nenhuma alteração em server.js ou configuracoes.html necessária.
