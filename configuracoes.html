Personalização das Teclas de Atalho

Configure as teclas para que sua equipe continue operando com os mesmos atalhos que usavam no sistema anterior (Ex: F1, F2, F8, F10, etc).

Otimização de Resolução & Escala da Tela

Escolha o perfil de resolução adequado ao seu monitor, notebook ou tablet. O sistema ajustará dinamicamente o tamanho das tabelas, botões, ícones e fontes para maximizar o aproveitamento de tela e garantir a usabilidade mais fluida possível.

A configuração é aplicada instantaneamente em todas as telas e salva no dispositivo.

    Encontre em: Apps Script → Implantar → Gerenciar implantações → URL do aplicativo web

    Encontre na URL da planilha: docs.google.com/spreadsheets/d/[ID AQUI]/edit

    Abrir Apps Script
    📖 Passo a passo de configuração
    1. Crie uma conta Google exclusiva para o Chef Cozinha
    2. Acesse sheets.google.com e crie uma nova planilha
    3. Copie o ID da planilha da URL e cole acima
    4. Na planilha: Extensões → Apps Script
    5. Delete o código padrão e cole o conteúdo do arquivo installer/apps-script/LicenseServer.gs
    6. Substitua SHEET_ID pelo ID da planilha
    7. Clique em Implantar → Novo implante → Aplicativo Web
    8. Configure: Execute como: Eu mesmo | Acesso: Qualquer pessoa
    9. Copie a URL gerada e cole no campo acima
    10. Clique em Salvar Configurações e depois Testar Conexão

    Integração com Maquininha de Cartão

    Conecte sua maquininha para enviar cobranças diretamente do caixa ao terminal, sem digitar o valor manualmente.

    🔵
    Mercado Pago Point
    API Integration — Smart / Pro
    Token de produção privado obtido no painel de desenvolvedores do Mercado Pago.
    Número de série da maquininha Point. Encontrado no menu Integração do próprio aparelho.
    🟢
    Stone / Ton
    StonePOS TEF Local — cliente rodando na máquina
    ⚙️ Pré-requisito: O Stone Client TEF deve estar instalado e rodando na mesma máquina do servidor. Baixe em: sdkweb.stone.com.br
    Código único do estabelecimento fornecido pela Stone/Ton no cadastro.
    Porta TCP em que o Stone Client TEF está escutando localmente. Padrão: 8080.
    🟠
    PagBank / PagSeguro
    Pagamento Presencial — Smart Terminal API
    📋 Requisito: Terminal PagBank Smart certificado. Token de integração obtido em dev.pagbank.com.br
    Token gerado no painel de desenvolvedores do PagBank. Uso em produção.
    Número de série do terminal PagBank Smart (encontrado no menu do aparelho).
    ⚙️
    SiTef Genérico
    Protocolo ABECS — Cielo, Getnet, Rede, Safra, Ticket
    ⚙️ Pré-requisito: Servidor SiTef instalado na rede local (fornecido pela sua operadora ou pelo integrador). O chef cozinha irá se comunicar com ele via TCP/IP.
    Número do terminal TEF configurado no servidor SiTef. Geralmente 8 dígitos.
    Código do estabelecimento comercial fornecido pela operadora (Cielo, Getnet, Rede, etc).

    Guia Rápido de Integração

    🔵
    Mercado Pago
    Acesse mercadopago.com.br → Seu negócio → Point → Integrar. Gere o Access Token e anote o Device ID da maquininha.
    🟢
    Stone / Ton
    Instale o Stone Client TEF no PC do caixa. Seu Stone Code é enviado por e-mail no cadastro. Porta padrão: 8080.
    🟠
    PagBank
    Acesse minha-conta.pagseguro.com.br → Integrações → Gerar token de produção. Terminal ID impresso no aparelho.
    ⚙️
    SiTef (Cielo/Getnet/Rede)
    Solicite o servidor SiTef à sua operadora ou integrador. Configure o IP e porta na rede local do estabelecimento.
